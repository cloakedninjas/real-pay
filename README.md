# Real Pay

A salary calculator that shows how your purchasing power changes over time when adjusted for inflation.
Enter your starting salary and any pay rises you've received to see whether your real wages have kept up with inflation.

## Purpose

Understanding nominal salary increases isn't enough—what matters is your real purchasing power. This tool:

- **Calculates inflation-adjusted salary** across multiple years
- **Compares nominal vs real values** to show true purchasing power
- **Tracks multiple pay rises** over time
- **Visualizes trends** with interactive charts
- **Supports multiple countries** with localized inflation data

Get instant insight into whether your pay rises have outpaced inflation or if you're actually earning less in real terms than when you started.

## Installation

Install dependencies:

```bash
npm install
```

## Usage

### Development

Run the development server:

```bash
npm run dev
```

### Build

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

### Testing

Run tests:

```bash
npm test
```

Run tests with UI:

```bash
npm run test:ui
```

### Linting

Check code quality:

```bash
npm run lint
```
